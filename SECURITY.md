# Security policy

Report suspected vulnerabilities in the encryption code privately, before
disclosing publicly: use GitHub's "Report a vulnerability" (Security tab), or
email info@spotvibes.com. Include affected files, a description, and steps
to reproduce. Reports are acknowledged, and reporters credited on request.

This code has not had an independent security audit and has not been compiled
or tested in a full build. Do not rely on it for anything critical without
review.
